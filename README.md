# Вечная память

Мрачная средневековая action-RPG от первого лица.

## Как скачать и запустить

1. Открой [Releases](../../releases/latest) и скачай `VechnayaPamyat.zip`, это 466 МБ.
2. Распакуй архив в любую папку. Из архива игра не запустится: `VechnayaPamyat.exe` и `VechnayaPamyat.pck` должны лежать рядом.
3. Запусти `VechnayaPamyat.exe`.
4. У игры нет цифровой подписи, поэтому Windows может показать окно «Windows защитила ваш компьютер». Нажми «Подробнее», затем «Выполнить в любом случае».

## Обновления

Начиная с версии 0.2 игра обновляется сама. При запуске она проверяет этот репозиторий, скачивает небольшой патч (папка `updates/`) и перезапускается. Полный архив заново качать не нужно, только когда выходит новая полная версия: об этом игра скажет в главном меню.

## Требования

- Windows 10/11, 64 бит.
- Видеокарта с поддержкой Vulkan или DirectX 12.

Сделано на Godot 4.7.
